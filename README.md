# 💎 NFT Ultraverse — Interactive NFT Gallery

### React · Web3-Style UI · AOS · React Slick

[Live Demo](https://keylan-internship-nft.vercel.app/) • [Repository](https://github.com/kingkey0101/Keylan-internship)

---

## Overview
**NFT Ultraverse** delivers a modern, animated NFT gallery experience inspired by Web3 interfaces. Built with React and React Slick, it features swipe-enabled carousels, smooth transitions, and a clean, dynamic layout designed for mobile-first browsing.

---

## Tech Stack
- **Frontend:** React.js, TailwindCSS, JavaScript (ES6+)
- **Animations:** React Slick, Axios, AOS (Animate On Scroll)  
- **Optimization:** Lazy loading, custom arrow components  
- **Deployment:** Vercel  
- **Version Control:** Git + GitHub workflow

---

## Features
- Swipeable, infinite NFT carousel with custom controls  
- Smooth AOS animations for dynamic content presentation  
- Mobile-first, responsive grid layout  
- Lazy-loaded images for fast rendering  
- Reusable React components with clean architecture
- Implemented countdown timer for limited sale items
